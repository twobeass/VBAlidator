# VBA175 — Duplicate label

**Severity:** 🔴 error    **Category:** `control_flow`    **Phase:** 2.11

## Description

The same line label is declared more than once in a procedure.

## Failing example

```vb
Sub S()
Done:
    Exit Sub
Done:
End Sub
```

## Compliant example

```vb
Sub S()
Done:
    Exit Sub
End Sub
```

## How to fix

Rename or remove the duplicate label.
