# VBA113 — Expected End With

**Severity:** 🔴 error    **Category:** `syntax`    **Phase:** 1.5

## Description

A `With` block has no matching `End With`.

## Failing example

```vb
With rng
    .Value = 1
```

## Compliant example

```vb
With rng
    .Value = 1
End With
```

## How to fix

Add the `End With` that closes the block.
