# VBA171 — Exit Do not within Do...Loop

**Severity:** 🔴 error    **Category:** `control_flow`    **Phase:** 2.11

## Description

`Exit Do` is only valid inside a `Do...Loop`.

## Failing example

```vb
Sub S()
    Exit Do
End Sub
```

## Compliant example

```vb
Sub S()
    Do
        Exit Do
    Loop
End Sub
```

## How to fix

Remove the `Exit Do` or place it inside a `Do` loop.
