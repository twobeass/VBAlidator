# VBA123 — Empty Enum not allowed

**Severity:** 🔴 error    **Category:** `type`    **Phase:** 1.6

## Description

An `Enum … End Enum` block must declare at least one member.

## Failing example

```vb
Enum Empty
End Enum
```

## Compliant example

```vb
Enum Color
    Red
End Enum
```

## How to fix

Add at least one member, or remove the empty Enum.
