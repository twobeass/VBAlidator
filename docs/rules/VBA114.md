# VBA114 — Select Case without End Select

**Severity:** 🔴 error    **Category:** `syntax`    **Phase:** 1.5

## Description

A `Select Case` block has no matching `End Select`.

## Failing example

```vb
Select Case x
    Case 1
        Debug.Print 1
```

## Compliant example

```vb
Select Case x
    Case 1
        Debug.Print 1
End Select
```

## How to fix

Add the `End Select` that closes the block.
