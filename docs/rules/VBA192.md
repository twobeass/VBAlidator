# VBA192 — Invalid #Const declaration

**Severity:** 🔴 error    **Category:** `preprocessor`    **Phase:** 3.8

## Description

A `#Const` directive must have the form `#Const Name = expression`.

## Failing example

```vb
#Const
```

## Compliant example

```vb
#Const DEBUG_BUILD = 1
```

## How to fix

Write `#Const Name = <constant expression>`.
