# VBA141 — Named argument specified more than once

**Severity:** 🔴 error    **Category:** `signature`    **Phase:** 2.9

## Description

The same named argument appears twice in one call.

## Failing example

```vb
Call S(a:=1, a:=2)
```

## Compliant example

```vb
Call S(a:=1, b:=2)
```

## How to fix

Pass each named argument at most once.
