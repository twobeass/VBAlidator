# VBA183 — Duplicate Deftype letter range

**Severity:** 🔴 error    **Category:** `placement`    **Phase:** 3.7

## Description

A letter cannot be covered by more than one `DefXxx` statement.

## Failing example

```vb
DefInt A-K
DefStr H-Z
```

## Compliant example

```vb
DefInt A-G
DefStr H-Z
```

## How to fix

Make the `DefXxx` letter ranges disjoint.
