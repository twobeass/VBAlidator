# VBA172 — Next control variable mismatch

**Severity:** 🔴 error    **Category:** `control_flow`    **Phase:** 2.11

## Description

The variable on `Next x` must match the loop's `For` counter.

## Failing example

```vb
For i = 1 To 10
    Debug.Print i
Next j
```

## Compliant example

```vb
For i = 1 To 10
    Debug.Print i
Next i
```

## How to fix

Use the same variable as the `For` counter, or a bare `Next`.
