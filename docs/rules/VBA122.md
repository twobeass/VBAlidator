# VBA122 — User-defined type without members

**Severity:** 🔴 error    **Category:** `type`    **Phase:** 1.6

## Description

A `Type … End Type` block must declare at least one member.

## Failing example

```vb
Type Empty
End Type
```

## Compliant example

```vb
Type Point
    x As Long
End Type
```

## How to fix

Add at least one field, or remove the empty Type.
