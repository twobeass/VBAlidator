# VBA184 — Duplicate Option statement

**Severity:** 🔴 error    **Category:** `placement`    **Phase:** 3.7

## Description

The same `Option` statement (Explicit/Compare/Base/Private Module) appears twice.

## Failing example

```vb
Option Explicit
Option Explicit
```

## Compliant example

```vb
Option Explicit
```

## How to fix

Remove the duplicate `Option` statement.
